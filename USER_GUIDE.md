# WordLite User Guide

Welcome to **WordLite**, a fast, lightweight, and offline desktop word processor for macOS and Windows.

---

## 1. Getting Started

### Creating a New Document
- Click **File &rarr; New &rarr; Blank Document** or click the **`+`** icon on the document tabs strip.
- Keyboard shortcut: **`Ctrl + N`** (Windows) or **`Cmd + N`** (macOS).

### Opening Documents
- Click **File &rarr; Open** or press **`Ctrl/Cmd + O`**.
- WordLite supports `.docx`, `.txt`, `.html`, `.md`, and `.rtf` formats.

### Saving Documents
- Click **File &rarr; Save** or press **`Ctrl/Cmd + S`**.
- WordLite saves atomically to prevent data corruption.
- To save with a new name, select **File &rarr; Save As**.

## 2. Ribbon Tabs Overview

### Home Tab
- **Clipboard:** Format Painter (copy and apply styling) and Clear Formatting.
- **Font:** Font Family, Font Size, Grow/Shrink Font, Bold (`Ctrl/Cmd + B`), Italic (`Ctrl/Cmd + I`), Underline (`Ctrl/Cmd + U`), Strikethrough, Subscript, Superscript, Font Color, and Highlight Color.
- **Paragraph:** Bulleted and Numbered lists, Indent/Outdent, Formatting Marks toggle (¶), Alignment (Left, Center, Right, Justify), Line Spacing (1.0 to 2.0).
- **Styles Gallery:** Apply predefined styles including Normal, Title, Subtitle, Heading 1–3, Quote, and Intense Quote.
- **Editing:** Find (`Ctrl/Cmd + F`), Replace (`Ctrl/Cmd + H`), and Select All (`Ctrl/Cmd + A`).

### Insert Tab
- **Pages:** Page Break (`Ctrl/Cmd + Enter`).
- **Tables:** Insert Table (3x3 grid), Add/Delete Rows and Columns, Merge/Split Cells, Delete Table.
- **Illustrations:** Insert Picture from local image files (PNG, JPEG, WebP) and Horizontal Line.
- **Links:** Insert or edit Hyperlinks (`Ctrl/Cmd + K`).
- **Header & Footer:** Configure header and footer text and page numbering.
- **Symbols:** Insert mathematical symbols, currency symbols, Greek letters, and current Date & Time.

### Layout Tab
- **Margins:** Select presets (Normal, Narrow, Moderate, Wide) or configure custom millimeter margins.
- **Orientation:** Switch between Portrait and Landscape.
- **Size:** Select A4, Letter, Legal, Executive, or A5.
- **Columns:** Choose 1, 2, or 3 columns.
- **Custom Setup:** Detailed Page Setup dialog for custom paper and margin dimensions.

### References Tab
- **Table of Contents:** Insert automatic Table of Contents derived from document headings.
- **Footnotes:** Insert Footnote or Endnote reference marks.
- **Captions:** Insert figure or table captions.

### Review Tab
- **Proofing:** Word Count dialog and offline spellcheck status.
- **Comments:** New Comment, Reply to comments, Resolve, and Delete comments.
- **Tracking:** Toggle Track Changes to record and audit insertions and deletions. Accept or Reject changes individually or in batch.
- **Compare:** Compare two versions of a document to highlight exact additions and deletions.
- **Protect:** Toggle Read-Only mode to prevent accidental edits.

### Mailings Tab
- **Start Mail Merge:** Load recipient data from CSV files.
- **Fields:** Insert personalized fields like `«FirstName»`, `«LastName»`, `«Email»`, `«Company»`.
- **Preview Results:** Step through records to review merged documents before export.

### View Tab
- **Views:** Print Layout, Draft, Read Mode, and Focus Mode (distraction-free writing).
- **Show/Hide:** Toggle Ruler, Navigation Pane (Outline), and Formatting Marks.
- **Zoom:** Presets for 50%, 75%, 100%, 125%, 150%, 200%, and Zoom In/Out controls.
- **Theme:** Switch between Word Blue Light Theme and Dark Theme.
